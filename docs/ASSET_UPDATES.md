# Assets added in the visual correction

All assets are bundled locally. There are no runtime requests to BMS or Unsplash.

- `collaboration-{480,800,1600}.webp`: Unsplash photo `photo-1522071820081-009f0129c71c`, Annie Spratt, people working together around a table. Source download: https://images.unsplash.com/photo-1522071820081-009f0129c71c?w=1600&q=85&fm=webp
- `conversation-{480,800,1600}.webp`: Unsplash photo `photo-1551836022-d5d88e9218df`, two people discussing work over a laptop. Source download: https://images.unsplash.com/photo-1551836022-d5d88e9218df?w=1600&q=85&fm=webp
- Photo copyright licence: https://unsplash.com/license. These are illustrative stock photographs, not BF staff/client portraits. Existing `assetsApproved` launch review remains required.
- `world-map.svg`: generated equirectangular land silhouette from Natural Earth's public-domain 110m land GeoJSON. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson. Terms: https://www.naturalearthdata.com/about/terms-of-use/. Antarctica omitted for the decorative layout. The only location marker rendered by the component is Hong Kong.
- Capsule text path and four principle icons: original inline SVGs in the repository.
